# \# Индивидуальные приказы на премию

# 

# Расширение для 1С, которое позволяет по документу «Премия» сформировать отдельный приказ на каждого выбранного сотрудника.

# 

# \## Что сделано

# 

# \- выбор проведённого документа «Премия»;

# \- вывод сотрудников с ФИО, табельным номером, должностью, подразделением и суммой премии;

# \- несколько строк премии одного сотрудника объединяются в один приказ;

# \- выбор одного или нескольких сотрудников, есть «Выбрать всех» и «Снять всех»;

# \- должность и подразделение определяются на дату документа;

# \- для каждого сотрудника формируется отдельный приказ;

# \- при повторном сохранении дубли файлов не создаются;

# \- ошибки при обработке одного сотрудника не останавливают остальных.

# 

# Для кадровых данных используется регистр `ТЗ\_КадроваяИстория`, для хранения присоединённых файлов — `ТЗ\_ПрисоединенныеФайлы`.

# 

# \## Установка

# 

# 1\. Открыть конфигуратор 1С.

# 2\. Перейти в \*\*Конфигурация → Расширения конфигурации\*\*.

# 3\. Добавить файл `ТЗ\_ИндивидуальныеПриказыНаПремию.cfe`.

# 4\. Обновить конфигурацию базы данных.

# 5\. Запустить 1С в пользовательском режиме.

# 

# \## Ограничение учебной версии

# 

# Проект разрабатывался в учебной версии 1С. В ней недоступно сохранение табличного документа в PDF, поэтому сам механизм PDF-сохранения в учебной базе проверить невозможно.

# 

# Основная логика формирования приказов и сохранения записей в `ТЗ\_ПрисоединенныеФайлы` проверена.

# 

# \## Структура

# 

# Основной объект расширения:

# 

# `ТЗ\_ИндивидуальныеПриказыНаПремию`

# 

# Используемые объекты имеют префикс `ТЗ\_`.
